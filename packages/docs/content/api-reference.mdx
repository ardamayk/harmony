# API Reference

HTTP API is contract-first.

## Source of truth

`packages/contracts/openapi.yaml` owns endpoint shapes, schemas, and operation IDs.

Generated outputs:

- TypeScript OpenAPI schema: `packages/api-client/src/generated/schema.ts`
- Public TypeScript domain types: aliases exported from `packages/api-client/src/index.ts`

## Runtime

- Scalar API reference: `/api/docs`
- Raw OpenAPI YAML: `/api/openapi.yaml`

Use the API reference at `/api/docs` for endpoint details. Keep MDX docs focused on product concepts, workflows, and architecture.

When adding API fields, edit the OpenAPI spec first, run `mise run generate`, then update handlers and UI callers.
