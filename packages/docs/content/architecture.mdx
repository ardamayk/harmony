# Architecture

Navidrome Replacement is a modular monolith with separate web, docs, contracts, and server packages.

## Source flow

```text
packages/contracts/openapi.yaml
  -> packages/api-client/src/generated/schema.ts
  -> packages/api-client/src/index.ts type aliases
  (the Music Server embeds the spec and serves it at /api/openapi.yaml)

packages/docs/content/*.mdx
  -> packages/docs/dist
  -> server/static/docs

web/src
  -> web/dist
  -> server/static/web

server/migrations (goose format)
  -> the Music Server's migrator at startup
  -> the schema sqlx checks every query against (server/.sqlx)
```

## Server modules

The Music Server is written in Rust (axum, sqlx on SQLite). Domain routes live in `server/src/modules`.

- `library`: artists, albums, tracks, covers, waveforms (read-only; the server never scans a folder)
- `search`: Library Search ranking over the prepared search data
- `managed_import`: Managed Import uploads, the Strict Import Profile (`server/src/inspect`), Import Preview, commit, Permanent Track and Album Deletion, Track Replacement
- `playback`: queue, queue events and range streaming
- `playlists`: playlists and the default Favorites playlist
- `preferences`: theme, layout, and playback preferences
- `radio`: saved stations, Radio Browser search, stream proxy
- `docs`: MDX docs, Swagger UI, OpenAPI YAML

Inside a module, `mod.rs` registers the routes and handles HTTP, `service.rs` owns the domain rules, and `repository.rs` is the only database access, with queries checked against the schema at compile time.

Each module exposes `routes()`, which `server/src/app.rs` merges into one router with the shared middleware (CORS, request timeout, panic recovery).

## Shared server utilities

HTTP JSON errors use `server/src/respond.rs` (`ApiError`), so the error envelope stays consistent:

```json
{
  "error": "bad_request",
  "code": "bad_request",
  "message": "Human-readable description"
}
```

## API client

`@repo/api-client` exports a stable `createApiClient` wrapper for web/UI code.

Domain types exported from `@repo/api-client` are aliases to generated OpenAPI schemas. Do not hand-copy schema fields into the wrapper.

## Static assets

The production Music Server embeds the built Web Client and docs at compile time (`rust-embed`), so `mise run server:build` builds them first.

After build, sync only the changed static target:

```bash
./scripts/sync-static.sh all   # web + docs
./scripts/sync-static.sh web   # SPA only
./scripts/sync-static.sh docs  # MDX docs only
```
