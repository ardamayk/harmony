# Getting Started

## Prerequisites

- [Rust](https://rustup.rs) (stable)
- [mise](https://mise.jdx.dev) (installs Node, pnpm and the Rust tools)

## Development

```bash
mise install
pnpm install
mise run dev:web
```

- API: http://localhost:8090
- Web dev server: http://localhost:3000 (proxies `/api` to the Music Server)

### Music library

Add music through **Managed Import**: open **Settings** in the web UI, click **Import Music**, and select audio files or a local folder (mp3, flac, ogg, m4a, opus, wav). Every file is validated strictly, shown in an Import Preview, and stored in Managed Storage only after you confirm.

Album matching uses Album Artist credits and the full Album title; year and Track Artist do not split an Album. Edition suffixes such as `(Deluxe)` remain distinct. Only identical file hashes are duplicates. Different bytes at the same Album position and title require an explicit Track Replacement or skipping; you can also create a separate Album.

Genre, year, and artwork are optional. For a new Album, review embedded covers, upload a JPEG/PNG, or continue without artwork. Existing Album covers are preserved. Recording Identification and its external services are no longer part of import.

The server never scans a server-side folder; Managed Import is the only way music enters the library.

### Managed Storage

Managed imports use one server-owned storage root. The server keeps a 2 GiB safety reserve by default and enforces configurable per-file and per-batch streaming limits:

```bash
export MANAGED_STORAGE_PATH=./data/managed
export MANAGED_STORAGE_RESERVE_BYTES=2147483648
export MANAGED_IMPORT_FILE_LIMIT_BYTES=2147483648
export MANAGED_IMPORT_BATCH_LIMIT_BYTES=4294967296
```

All byte-count settings use base-10 integer strings. Set `MANAGED_STORAGE_RESERVE_BYTES=0` only when intentionally disabling the safety reserve.

## Production build

```bash
mise run build
mise run server:start
```

Mise is the canonical interface for development and CI tasks. Run `mise run ci` for static checks and unit tests and `mise run ci:integration` for integration tests. Target one artifact or domain with commands such as `mise run web:build`, `mise run server:test`, and `mise run desktop:check`.

### Git hooks

`pnpm install` enables the Vite+ Git hooks. Pre-commit runs `vp staged` on staged TypeScript, JSON, and Rust sources, and OpenAPI drift verification only when generation inputs are staged.

These hooks provide bypassable local feedback; CI is authoritative. Pass `--no-verify` to `git commit` or `git push` when needed. Hook installation is disabled in CI and production dependency installs. When `graphify-out/` exists, Graphify post-commit and branch-switch updates run if `graphify` is available on `PATH`; otherwise they intentionally do nothing.

Single binary serves:

- React SPA at `/`
- MDX product docs at `/docs/`
- Scalar API reference at `/api/docs`
- OpenAPI YAML at `/api/openapi.yaml`
